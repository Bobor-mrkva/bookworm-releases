# Bookworm Releases

Built installers and the auto-update feed for [Bookworm](https://github.com/Bobor-mrkva/bookworm), a local AI-DM TTRPG app.

This repo is intentionally source-free — it only exists so the app's built-in updater
(Sparkle) has a public URL to check. The actual source lives in a private repo.

- `appcast.xml` — the update feed the app checks
- Each [Release](../../releases) — a signed `.dmg` installer for that version
